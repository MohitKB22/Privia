PRIVIA 1.0.0 is the first public release: a private, local-first AI assistant
for your desktop.

## Downloads

| System | File |
|---|---|
| macOS, Apple Silicon | `PRIVIA-1.0.0-macos-arm64.dmg` |
| macOS, Intel | `PRIVIA-1.0.0-macos-x64.dmg` |
| Windows 10/11, 64-bit | `PRIVIA-1.0.0-windows-x64-setup.exe` or `.msi` |
| Linux x86-64 | `.deb`, `.rpm` or `.AppImage` |

Check a download against `SHA256SUMS.txt`. These installers are **not
code-signed**: macOS asks you to approve the first launch in System Settings →
Privacy & Security, and Windows SmartScreen shows "More info → Run anyway".

## What is in it

- **AI Workspace** with streaming replies, Markdown and code, stop, copy,
  regenerate, file attachments, hold-to-talk and a model selector.
- **My Files, Memory, Notes, Planner and Email**, all stored on your computer.
- **Approvals bound to the exact action:** sending email, deleting files,
  changing events and running commands always show the precise action first.
- **Activity** records every tool call, approval and refusal; the **Privacy
  Center** exports or deletes your data.
- **Local models through Ollama**, switchable in the app. Cloud providers are
  optional and off by default.
- First-run setup that checks your system, finds or helps install a model, and
  grants access one item at a time.

## Requirements

- For AI replies: [Ollama](https://ollama.com/download) with a model, for
  example `ollama pull llama3.2:3b` (8 GB RAM) or `llama3.1:8b` (16 GB RAM).
  Without one, PRIVIA runs its offline planner.
- No account, no subscription, no internet connection for local use.
